Use `StatNum` when a number is the point of the card. Numerals are heroes: the load, the week, the streak.

```jsx
<StatNum label="lb · working max">185</StatNum>
<StatNum size="md">wk 3</StatNum>
```

Always tabular so digits don't shift between renders. Ink-colored — if you want it volt, you want `VoltSlab` instead.
